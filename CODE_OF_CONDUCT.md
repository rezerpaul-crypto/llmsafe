# Code of Conduct

## Our commitment

LLMSafe is committed to a welcoming, respectful, and harassment-free community. We value
constructive disagreement, careful security work, and participation from people with different
backgrounds and levels of experience.

## Expected behavior

- Discuss ideas and people with respect.
- Give specific, actionable feedback and assume good intent while addressing harmful impact.
- Protect credentials, private source code, personal data, and embargoed vulnerability details.
- Accept maintainer decisions gracefully and use the documented appeal path when needed.
- Credit other people's work and disclose relevant conflicts of interest.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, doxxing, deliberate intimidation,
repeated disruption, impersonation, and publishing another person's private information without
permission are not acceptable. Security research does not excuse privacy violations, service
disruption, or access beyond what is needed to demonstrate an issue.

## Scope

This code applies in the repository, issue tracker, pull requests, project-managed communication,
and public spaces where someone is representing LLMSafe.

## Reporting conduct concerns

Do not disclose sensitive details in a public issue. Contact the maintainer through the private
contact method on the [maintainer's GitHub profile](https://github.com/rezerpaul-crypto). Include
links or screenshots, the date, and a concise description of what happened. Reports will be kept
as confidential as practical and acknowledged within five business days when possible.

If a report concerns the current maintainer or personal safety, use GitHub's platform reporting
and blocking tools. LLMSafe currently has one maintainer and cannot offer an independent internal
review; this limitation is documented rather than promising a process the project cannot provide.

Security vulnerabilities in LLMSafe itself follow [SECURITY.md](SECURITY.md), not this conduct
reporting path.

## Enforcement

The maintainer may edit or remove content, issue a private or public warning, temporarily limit
participation, or permanently ban a participant. The response will be proportionate to severity,
impact, context, and prior behavior. Decisions should include a concise reason unless doing so
would expose a reporter or sensitive security information.
